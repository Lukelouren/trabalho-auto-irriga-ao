# Horta Inteligente

Protótipo simples de um projeto escolar para acompanhar a umidade do solo, a temperatura e o estado da irrigação.

## Como abrir

1. Abra a pasta do projeto no computador.
2. Clique duas vezes no arquivo `index.html`.
3. Escolha um navegador para abrir a página.

O projeto usa HTML, CSS e JavaScript puro. Não é necessário instalar nenhuma dependência.

## Explicação dos arquivos

- `index.html`: contém a estrutura da página, os textos, os botões e as seções “Saiba mais”.
- `style.css`: define as cores, os tamanhos, o layout e a aparência responsiva.
- `script.js`: controla as leituras simuladas, o botão de irrigação, o gráfico, as configurações e as abas.

## Como usar os botões

- `⚙️`: abre as configurações.
- `Aumentar texto`: aumenta o tamanho da fonte da página.
- `Cor de fundo`: troca a cor de fundo entre claro, verde e azul.
- `Mostrar “Sair”`: mostra ou esconde o botão de saída.
- `Ligar irrigação` / `Desligar irrigação`: liga ou desliga a irrigação no modo manual.
- `Voltar ao automático`: volta o sistema para o controle automático.
- `Simular nova leitura`: troca os valores de umidade e temperatura, sem conectar hardware.
- `Orientações`, `Educacional` e `Sobre o projeto`: mostram diferentes informações sobre a horta.
- `Sair`: encerra a simulação e esconde o conteúdo principal.

> A irrigação e as leituras são simuladas. O site não controla equipamentos reais.
